# VM

A simple virtual machine and custom assembly language interpreter written in Python.

VM is a register-based virtual machine that executes hexadecimal machine instructions generated by its own assembler. It features a custom instruction set, 16 general-purpose registers, stack operations, arithmetic, jumps, and runtime verbose-mode switching.

## Features

- Custom assembly language (`.asm`)
- Hexadecimal machine code (`.hex`)
- 16 general-purpose registers (`R0`–`R15`)
- 1024-element stack
- Arithmetic operations
- Register-to-register data movement
- Unconditional jumps
- Stack manipulation
- Runtime verbose-mode toggling
- Configurable execution through command-line arguments

## Project Structure

```text
├── main.asm
└── main.hex
```

| File | Description |
|---|---|
| `vm.py` | Virtual machine and instruction executor |
| `assembler.py` | Converts assembly instructions into hexadecimal machine code |
| `main.asm` | Example assembly program |
| `main.hex` | Generated machine code |

## Architecture

### Registers

VM contains 16 general-purpose registers:

```text
R0, R1, R2, R3,
R4, R5, R6, R7,
R8, R9, R10, R11,
R12, R13, R14, R15
```

All registers are initialized to `0`.

### Stack

The VM has a stack containing 1024 elements.

It uses a stack pointer (`sp`) to keep track of the current stack position.

Supported operations:

- `PUSH` – Pushes a register's value onto the stack.
- `POP` – Retrieves the top value from the stack into a register.
- `VIEW_STACK` – Displays stack contents.

### Instruction Encoding

Instructions are represented as hexadecimal strings.

General format:

```text
0x[OPCODE][REGISTER][PARAMETER]
```

| Field | Description |
|---|---|
| OPCODE | Identifies the instruction |
| REGISTER | Specifies the destination or target register |
| PARAMETER | Contains an immediate value, source register, or other argument |

The register field occupies one hexadecimal digit.

The parameter occupies the remaining hexadecimal digits.

## Instruction Set

| Instruction | Opcode | Operands | Description |
|---|---|---|---|
| HALT | `0x00` | None | Stops execution |
| LOAD | `0x10` | Register, Value | Loads an immediate value into a register |
| MOV | `0x11` | Destination, Source | Copies one register's value into another |
| PRINT | `0x15` | Register | Prints a register's value |
| ADD | `0x20` | Destination, Source | Adds a source register to the destination |
| SUB | `0x21` | Destination, Source | Subtracts a source register from the destination |
| JMP | `0x25` | Address | Unconditionally jumps to an instruction index |
| PUSH | `0x30` | Register | Pushes a register onto the stack |
| POP | `0x31` | Register | Pops the stack into a register |
| VIEW_STACK | `0x32` | Count | Displays the requested number of stack elements |
| SLEEP | `0x40` | Seconds | Pauses execution |
| VERBOSE | `0xFF` | None | Toggles verbose mode |

## Assembly Syntax

Instructions are written using their mnemonic names.

Operands are separated using commas.

Example:

```asm
LOAD R0, 10
LOAD R1, 20

ADD R0, R1

PRINT R0

HALT
```

Comments begin with `#`.

```asm
# This is a comment

LOAD R0, 100
PRINT R0
HALT
```

## Usage

### Requirements

- Python 3

### Assemble and execute

```bash
python assembler.py main.asm
```

This automatically assembles the source file into `main.hex` and executes it.

### Assemble only

```bash
python assembler.py build main.asm
```

### Assemble with a custom output filename

```bash
python assembler.py build main.asm -o output.hex
```

### Execute an existing HEX file

```bash
python assembler.py run main.hex
```

### Explicitly assemble and execute

```bash
python assembler.py build-run main.asm
```

### Execute directly through the VM

```bash
python vm.py main.hex
```

## Example Program

```asm
# Basic arithmetic example

LOAD R0, 10
LOAD R1, 20

ADD R0, R1

PRINT R0

HALT
```

Expected output:

```text
[PRINT] Register R0 contains value: 30
```

## Verbose Mode

Verbose mode displays information about instruction execution.

It is disabled by default.

Use the `VERBOSE` instruction to toggle it:

```asm
VERBOSE

LOAD R0, 10
LOAD R1, 20

ADD R0, R1

PRINT R0
HALT
```

Verbose mode displays execution information such as register updates, arithmetic operations, and jumps.

## Current Limitations

- No conditional jump instructions.
- No comparison instructions.
- No memory management beyond registers and the stack.
- No assembler labels or symbolic jump targets.
- Stack bounds are not currently checked.
- Arithmetic uses Python integers without fixed-width overflow.
- No executable binary format yet.

## Future Plans

Potential improvements:

- Conditional jumps (`JE`, `JNE`, `JG`, `JL`)
- Comparison instructions
- Labels in assembly
- Better error handling
- Stack overflow and underflow protection
- More arithmetic and logical instructions
- A dedicated executable file format
- Packaging the VM and assembler into a standalone executable

import sys
from vm import VM
import argparse
from pathlib import Path



OPCODES = {
    'HALT': 0x00,
    'LOAD': 0x10,
    'MOV': 0x11,
    'PRINT': 0x15,
    'ADD': 0x20,
    'SUB': 0x21,
    'JMP': 0x25,
    'PUSH': 0x30,
    'POP': 0x31,
    'VIEW_STACK': 0x32,
    'SLEEP': 0x40,
    'VERBOSE': 0xFF
}
REGISTER_COUNTS = {
    'HALT': 0,
    'LOAD': 1,
    'MOV': 2,
    'PRINT': 1,
    'ADD': 2,
    'SUB': 2,
    'JMP': 0,
    'PUSH': 1,
    'POP': 1,
    'VIEW_STACK': 0,
    'SLEEP': 0,
    'VERBOSE': 0
}

def parse_number(operand: str) -> int:
    try:
        return int(operand, 0)
    except ValueError:
        raise ValueError(f"Invalid number: {operand}")

def parse_register(operand: str) -> int:
    if not operand.upper().startswith('R'):
        raise ValueError(f"Expected a register, got: {operand}")

    try:
        reg = int(operand[1:])
    except ValueError:
        raise ValueError(f"Invalid register: {operand}")

    if not 0 <= reg <= 15:
        raise ValueError(f"Register out of range: {operand}")

    return reg

def parse(line: str):
    line = line.strip()

    if not line or line.startswith('#'):
        return None

    parts = line.split(maxsplit=1)
    instr = parts[0].upper()

    if instr not in OPCODES:
        raise ValueError(f"Unknown instruction: {instr}")

    operands = (
        [operand.strip() for operand in parts[1].split(',')]
        if len(parts) > 1 else []
    )

    validate_operands(instr, operands)

    return instr, operands

def validate_operands(instr: str, operands: list):
    expected_counts = {
        'HALT': 0,
        'LOAD': 2,
        'MOV': 2,
        'PRINT': 1,
        'ADD': 2,
        'SUB': 2,
        'JMP': 1,
        'PUSH': 1,
        'POP': 1,
        'VIEW_STACK': 1,
        'SLEEP': 1,
        'VERBOSE': 0
    }

    if len(operands) != expected_counts[instr]:
        raise ValueError(
            f"{instr} expects {expected_counts[instr]} operands, "
            f"got {len(operands)}"
        )

    register_positions = {
        'LOAD': [0],
        'MOV': [0, 1],
        'PRINT': [0],
        'ADD': [0, 1],
        'SUB': [0, 1],
        'PUSH': [0],
        'POP': [0]
    }

    numeric_positions = {
        'LOAD': [1],
        'JMP': [0],
        'VIEW_STACK': [0],
        'SLEEP': [0]
    }

    for position in register_positions.get(instr, []):
        parse_register(operands[position])

    for position in numeric_positions.get(instr, []):
        parse_number(operands[position])

def encode(instr: str, operands: list) -> str:
    opcode = OPCODES[instr]

    if instr == 'HALT' or instr == 'VERBOSE':
        return f"0x{opcode:02X}000"

    if instr == 'LOAD':
        reg = parse_register(operands[0])
        value = parse_number(operands[1])
        return f"0x{opcode:02X}{reg:X}{value:X}"

    if instr in ('ADD', 'SUB', 'MOV'):
        reg = parse_register(operands[0])
        src = parse_register(operands[1])
        return f"0x{opcode:02X}{reg:X}{src:X}"

    if instr in ('PRINT', 'PUSH', 'POP'):
        reg = parse_register(operands[0])
        return f"0x{opcode:02X}{reg:X}0"

    if instr in ('JMP', 'VIEW_STACK', 'SLEEP'):
        value = parse_number(operands[0])
        return f"0x{opcode:02X}0{value:X}"

    raise ValueError(f"Cannot encode instruction: {instr}")

def assemble(lines: list[str]) -> list[str]:
    machine_code = []

    for line_number, line in enumerate(lines, start=1):
        try:
            parsed = parse(line)

            if parsed is None:
                continue

            instr, operands = parsed
            machine_code.append(encode(instr, operands))

        except ValueError as error:
            raise ValueError(f"Line {line_number}: {error}") from error

    return machine_code

def write_output(machine_code: list[str], filename: str):
    with open(filename, 'w') as f:
        f.write('\n'.join(machine_code))
        f.write('\n')


def main():
    parser = argparse.ArgumentParser(
        prog="vm",
        description="Assembler and virtual machine"
    )

    subparsers = parser.add_subparsers(dest="command", required=True)

    build_parser = subparsers.add_parser(
        "build", help="Assemble an .asm file"
    )
    build_parser.add_argument("source", type=Path)
    build_parser.add_argument("-o", "--output", type=Path)

    run_parser = subparsers.add_parser(
        "run", help="Run an existing .hex file"
    )
    run_parser.add_argument("program", type=Path)

    build_run_parser = subparsers.add_parser(
        "build-run", help="Assemble and execute an .asm file"
    )
    build_run_parser.add_argument("source", type=Path)
    build_run_parser.add_argument("-o", "--output", type=Path)

    if len(sys.argv) > 1 and sys.argv[1].lower().endswith(".asm"):
        sys.argv.insert(1, "build-run")
    
    args = parser.parse_args()

    try:
        if args.command in ("build", "build-run"):
            lines = args.source.read_text().splitlines()
            machine_code = assemble(lines)

            output = args.output or args.source.with_suffix(".hex")
            write_output(machine_code, str(output))

            print(f"Assembly successful: {output}")

            if args.command == "build-run":
                VM().execute(machine_code)

        elif args.command == "run":
            machine_code = args.program.read_text().splitlines()
            VM().execute(machine_code)

    except (OSError, ValueError) as error:
        print(f"Error: {error}", file=sys.stderr)
        sys.exit(1)


if __name__ == "__main__":
    main()

import sys
import time

OP_HALT = 0x00
OP_LOAD = 0x10
OP_MOV = 0x11
OP_PRINT = 0x15
OP_ADD = 0x20
OP_SUB = 0x21
OP_JMP = 0x25
OP_PUSH = 0x30
OP_POP = 0x31
OP_VIEW_STACK = 0x32
OP_SLEEP = 0x40
OP_VERBOSE = 0xFF

class VM:
    def __init__(self):
        self.registers = [0] * 16
        self.stack = [0] * 1024
        self.running = True
        self.sp = 0
        self.verbose = False

    def parse(self, line: str):
        line = line.strip()
        if not line.startswith('0x') or len(line) < 5:
            print("Skipping line[comment]: ", line)
            return None
        try:
            op_str = line[2:4]
            reg_str = line[4:5]
            param_str = line[5:]

            opcode = int(op_str, 16)
            reg = int(reg_str, 16)
            param = int(param_str, 16) if param_str else 0

            return {'opcode': opcode, 'reg': reg, 'param': param}
        except ValueError:
            print('ERROR: Failed to parse valid hex data from line: ', line)
            return None

    def execute(self, program: list):
        print("\n-------------Starting VM-------------\n")
        
        program = [self.parse(line) for line in program]
        program = [inst for inst in program if inst is not None]

        pc = 0
        self.running = True

        while self.running and pc < len(program):
            inst = program[pc]
            pc += 1
            opcode = inst['opcode']
            reg = inst['reg']
            param = inst['param']

            if opcode == OP_VERBOSE:
                self.verbose = not self.verbose
                print(f"Verbose is set to {self.verbose}")

            elif opcode == OP_LOAD:
                self.registers[reg] = param
                if self.verbose: print(f"[LOAD] Register R{reg} contains value: {param}") 

            elif opcode == OP_ADD:
                src_reg = param
                self.registers[reg] += self.registers[src_reg]
                if self.verbose: print(f"[ADD] Added R{src_reg} into R{reg}. New R{reg} value: {self.registers[reg]}") 
                
            elif opcode == OP_SUB:
                src_reg = param
                self.registers[reg] -= self.registers[src_reg]
                if self.verbose: print(f"[SUB] Subtracted R{src_reg} into R{reg}. New R{reg} value: {self.registers[reg]}")

            elif opcode == OP_MOV:
                src_reg = param
                self.registers[reg] = self.registers[src_reg]
                if self.verbose: print(f"[MOV] Mover value of R{src_reg} to R{reg}")
            
            elif opcode == OP_PRINT:
                print(f"[PRINT] Register R{reg} contains value: {self.registers[reg]}") 

            elif opcode == OP_JMP:
                pc = param
                if self.verbose: print(f"[JMP] Jumped to address: {param}") 

            elif opcode == OP_PUSH:
                self.stack[self.sp] = self.registers[reg]
                self.sp += 1
                # print(self.stack)
                if self.verbose: print(f"[STACK_PUSH] Pushed value of R{reg} to stack") 
            
            elif opcode == OP_POP:
                self.registers[reg] = self.stack[self.sp - 1] 
                self.sp -= 1
                self.stack[self.sp] = 0
                if self.verbose: print(f"[STACK_POP] Popped value of stack to R{reg}") 

            elif opcode == OP_VIEW_STACK:
                print([self.stack[x] for x in range(param)])


            elif opcode == OP_SLEEP:
                time.sleep(param)

            elif opcode == OP_HALT:
                self.running = False
                if self.verbose: print("[HALT] Halted VM") 
                
            else:
                print(f"Error: Unknown Opcode 0x{opcode:02X} encountered at instruction index {pc-1}")
                self.running = False

        print("\n-------------Terminated VM-------------\n")
        
if __name__ == "__main__":
    if len(sys.argv) < 2:
