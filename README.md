# VM

A simple virtual machine and custom assembly language interpreter written in Python.

VM is a register-based virtual machine that executes hexadecimal machine instructions generated by its own assembler. It features a custom instruction set, 16 general-purpose registers, stack operations, arithmetic, jumps, and runtime verbose-mode switching.

## Features

- Custom assembly language (`.asm`)
- Hexadecimal machine code (`.hex`)
- 16 general-purpose registers (`R0`–`R15`)
- 1024-element stack
- Arithmetic operations
- Register-to-register data movement
- Unconditional jumps
- Stack manipulation
- Runtime verbose-mode toggling
- Configurable execution through command-line arguments

## Architecture

### Registers

VM contains 16 general-purpose registers:

```text
R0, R1, R2, R3,
R4, R5, R6, R7,
R8, R9, R10, R11,
R12, R13, R14, R15
```

All registers are initialized to `0`.

### Stack

The VM has a stack containing 1024 elements.

It uses a stack pointer (`sp`) to keep track of the current stack position.

Supported operations:

- `PUSH` – Pushes a register's value onto the stack.
- `POP` – Retrieves the top value from the stack into a register.
- `VIEW_STACK` – Displays stack contents.

### Instruction Encoding

Instructions are represented as hexadecimal strings.

General format:

```text
0x[OPCODE][REGISTER][PARAMETER]
```

| Field | Description |
|---|---|
| OPCODE | Identifies the instruction |
| REGISTER | Specifies the destination or target register |
| PARAMETER | Contains an immediate value, source register, or other argument |

The register field occupies one hexadecimal digit.

The parameter occupies the remaining hexadecimal digits.

## Instruction Set

| Instruction | Opcode | Operands | Description |
|---|---|---|---|
| HALT | `0x00` | None | Stops execution |
| LOAD | `0x10` | Register, Value | Loads an immediate value into a register |
| MOV | `0x11` | Destination, Source | Copies one register's value into another |
| PRINT | `0x15` | Register | Prints a register's value |
| ADD | `0x20` | Destination, Source | Adds a source register to the destination |
| SUB | `0x21` | Destination, Source | Subtracts a source register from the destination |
| JMP | `0x25` | Address | Unconditionally jumps to an instruction index |
| PUSH | `0x30` | Register | Pushes a register onto the stack |
| POP | `0x31` | Register | Pops the stack into a register |
| VIEW_STACK | `0x32` | Count | Displays the requested number of stack elements |
| SLEEP | `0x40` | Seconds | Pauses execution |
| VERBOSE | `0xFF` | None | Toggles verbose mode |

## Assembly Syntax

Instructions are written using their mnemonic names.

Operands are separated using commas.

Example:

```asm
LOAD R0, 10
LOAD R1, 20

ADD R0, R1

PRINT R0

HALT
```

Comments begin with `#`.

```asm
# This is a comment

LOAD R0, 100
PRINT R0
HALT
```

## Usage

### Requirements

- Python 3

### Assemble and execute

```bash
python assembler.py main.asm
```

This automatically assembles the source file into `main.hex` and executes it.

### Assemble only

```bash
python assembler.py build main.asm
```

### Assemble with a custom output filename

```bash
python assembler.py build main.asm -o output.hex
```

### Execute an existing HEX file

```bash
python assembler.py run main.hex
```

### Explicitly assemble and execute

```bash
python assembler.py build-run main.asm
```

### Execute directly through the VM

```bash
python vm.py main.hex
```

## Example Program

```asm
# Basic arithmetic example

LOAD R0, 10
LOAD R1, 20

ADD R0, R1

PRINT R0

HALT
```

Expected output:

```text
[PRINT] Register R0 contains value: 30
```

## Verbose Mode

Verbose mode displays information about instruction execution.

It is disabled by default.

Use the `VERBOSE` instruction to toggle it:

```asm
VERBOSE

LOAD R0, 10
LOAD R1, 20

ADD R0, R1

PRINT R0
HALT
```

Verbose mode displays execution information such as register updates, arithmetic operations, and jumps.

## Current Limitations

- No conditional jump instructions.
- No comparison instructions.
- No memory management beyond registers and the stack.
- No assembler labels or symbolic jump targets.
- Stack bounds are not currently checked.
- Arithmetic uses Python integers without fixed-width overflow.
- No executable binary format yet.
